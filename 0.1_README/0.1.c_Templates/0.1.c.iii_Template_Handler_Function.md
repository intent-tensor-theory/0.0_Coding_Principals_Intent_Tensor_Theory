# 0.1.c.iii Template: Handler Function Architecture

**Purpose:** Reference template for creating Ghostless event handlers.

## Handler Pattern

```typescript
// [Level].[sublevel]_fileHandle[Event][Domain][Object].ts

export function handle[Event][Domain][Object]By[Context][Level](
  [param]: [Type]
): void | Promise<void> {

  logger.log('🎯 [FILE_PATH].handle[Event][Domain][Object]By[Context][Level]: ' +
    'User triggered [event] with [context]=' + [param]);

  // Update state
  intentStateEngine[Domain][Level].set[Property]([param]);

  // Trigger side effects
  [sideEffect]();

  // Re-render if needed
  render[Object][Domain]Intent[Context][Level]();

  logger.log('✅ [FILE_PATH].handle[Event][Domain][Object]By[Context][Level]: ' +
    'Handler completed successfully');
}
```

## Naming Conventions

- **Function Name:** `handle[Event][Domain][Object]By[Context][Level]()`
- **File Name:** `[level].[sublevel]_fileHandle[Event][Domain][Object].ts`
- **Events:** Click, Submit, Change, Focus, Blur, etc.

## Example: Click Handler for Dashboard Item

```typescript
// 1.0.c_fileHandleClickDashboardItemCard.ts

export function handleClickDashboardItemCardByItemIdPrimary(
  itemId: string
): void {

  logger.log('🎯 1.0.c_fileHandleClickDashboardItemCard.handleClickDashboardItemCardByItemIdPrimary: ' +
    'User clicked dashboard item with itemId=' + itemId);

  // Update selected item in state
  intentStateEngineDashboardPrimary.setSelectedItemId(itemId);

  // Fetch detailed data
  fetchDashboardItemDetailsByItemIdFromAPIValidated(itemId);

  // Re-render detail view
  renderDashboardDetailViewIntentBySelectedItemId();

  logger.log('✅ 1.0.c_fileHandleClickDashboardItemCard: Handler completed');
}
```

## Example: Form Submit Handler

```typescript
// 2.3.d_fileHandleSubmitPlatformForm.ts

export async function handleSubmitPlatformFormDataValidatedLevelTwo(
  formDataValidated: PlatformFormDataType
): Promise<void> {

  logger.log('🎯 2.3.d_fileHandleSubmitPlatformForm.handleSubmitPlatformFormDataValidatedLevelTwo: ' +
    'Submitting platform form with platformName=' + formDataValidated.platformName);

  // Set loading state
  intentStateEnginePlatformLevelTwo.setIsSubmittingForm(true);

  try {
    // Submit to API
    const responseFromAPI = await submitPlatformDataToAPIEndpointValidated(formDataValidated);

    logger.log('✅ 2.3.d_fileHandleSubmitPlatformForm: API response received with status=' +
      responseFromAPI.status);

    // Update state with new platform
    intentStateEnginePlatformLevelTwo.addPlatformToList(responseFromAPI.platform);

    // Re-render platform list
    renderListPlatformsIntentByActivePlatforms();

  } catch (error) {
    logger.log('🚨 2.3.d_fileHandleSubmitPlatformForm: Submission failed with error=' + error.message);

    intentStateEnginePlatformLevelTwo.setSubmissionError(error.message);
  } finally {
    intentStateEnginePlatformLevelTwo.setIsSubmittingForm(false);
  }
}
```
