# 0.1.d.i ShellIndex Generator Specification

**Purpose:** Automated generator for creating ShellIndex.json from Ghostless codebases.

---

## What is ShellIndex.json?

The **master glyph lattice** of the application - a complete semantic map of every file, folder, component, function, and state engine.

## Generator Requirements

### Input
- Root directory of Ghostless codebase
- Configuration (optional): file patterns, exclusions

### Output
```json
{
  "schemaVersion": "1.0.0",
  "generatedAt": "2025-01-27T10:00:00Z",
  "applicationName": "extracted-from-root-folder",
  "layers": { /* layer mapping */ },
  "components": { /* component mapping */ },
  "stateEngines": { /* state engine mapping */ },
  "functions": { /* function mapping */ }
}
```

### Algorithm

1. **Scan Directory Structure**
   - Identify Ghostless folders (`[level].[sublevel]_folder[Domain]`)
   - Extract layer hierarchy

2. **Parse Files**
   - Find all Ghostless files (`[level].[sublevel]_file[Domain][Intent]`)
   - Extract exports, imports, dependencies

3. **Map Components**
   - Identify components (`Component[Domain][Type][Level]`)
   - Extract props, events

4. **Map State Engines**
   - Identify state engines (`intentStateEngine[Domain][Level]`)
   - Extract state properties, mutators

5. **Map Functions**
   - Extract all exported functions
   - Determine type (handler, validator, fetcher, renderer)

6. **Build Dependency Graph**
   - Trace imports between files
   - Create edges in semantic graph

## CLI Usage

```bash
# Generate ShellIndex
ghostless-shell-index generate ./src

# Generate with options
ghostless-shell-index generate ./src --output ./ShellIndex.json --exclude "**/*.test.ts"

# Validate existing ShellIndex
ghostless-shell-index validate ./ShellIndex.json

# Diff two ShellIndex files
ghostless-shell-index diff ./ShellIndex.old.json ./ShellIndex.new.json
```
