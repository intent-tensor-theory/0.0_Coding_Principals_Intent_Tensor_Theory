# 0.1.d.ii IntentGlossary Generator Specification

**Purpose:** Automated generator for creating IntentGlossary.json - the behavioral map of all functions.

---

## What is IntentGlossary.json?

The **nervous system** of the application - maps every function's intent, inputs, outputs, side effects, and execution chains.

## Generator Requirements

### Input
- Codebase directory
- ShellIndex.json (optional, for cross-reference)

### Output
```json
{
  "schemaVersion": "1.0.0",
  "generatedAt": "2025-01-27T10:00:00Z",
  "functions": { /* function behavioral map */ },
  "stateEngines": { /* state engine mutators map */ },
  "components": { /* component props/events map */ }
}
```

### Algorithm

1. **Parse Function Signatures**
   - Extract parameters, return types
   - Determine function intent from name

2. **Analyze Function Body**
   - Identify state mutations
   - Identify function calls (triggers)
   - Identify side effects (API calls, DOM mutations, logs)

3. **Map Execution Chains**
   - Trace what triggers this function
   - Trace what this function triggers

4. **Extract Documentation**
   - Parse JSDoc comments
   - Infer intent from Ghostless naming

## CLI Usage

```bash
# Generate IntentGlossary
ghostless-intent-glossary generate ./src

# Generate with ShellIndex reference
ghostless-intent-glossary generate ./src --shell-index ./ShellIndex.json

# Query glossary
ghostless-intent-glossary query "handleClick*" --type HANDLER

# Show execution chain
ghostless-intent-glossary chain renderDashboardViewPrimaryByUserId
```
